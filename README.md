# ⚔️ RPG Narrator

An AI-powered pen & paper RPG game master, playable in the browser or installable as a PWA.

**[▶ Play now](https://YOUR-USERNAME.github.io/rpg-narrator)**

---

## Features

- 11 scenarios — Dark Fantasy, Cyberpunk, Cosmic Horror, Space Frontier and more
- 1–4 players with full character creation (stats, skills, backstory)
- AI narration powered by Claude Sonnet
- Voice input & ElevenLabs TTS narration
- Atmospheric sound effects
- Save / load game slots
- Installable as a mobile app (PWA)

## Setup

Open the app and enter your **Anthropic API key** in Settings (⚙️).  
Optionally add an **ElevenLabs key** for voice narration and sound effects.

## Install as mobile app

**Android:** Chrome menu (⋮) → *Install App*  
**iOS:** Safari Share (↑) → *Add to Home Screen*
